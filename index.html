📜 Regras do Campeonato

1. Pontuação: Cada time recebe notas de 0 a 3 em três critérios (Assiduidade, Performance, Segurança) por rodada ou fase.

2. Cartões Amarelos: Servem como indicador visual de advertência para os jogadores, mas não descontam pontos diretamente.

3. Classificação: O time com a maior soma de pontos na competição vence.

4. Desempate: Em caso de empate, o time com o nome em ordem alfabética fica à frente.
